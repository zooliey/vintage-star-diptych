# Vintage Star Diptych

`vintage-star-diptych` 是一个可复用的 Codex Skill：把用户上传的照片制作成一张 3:4 竖版、上下等高的复古星字双宫格海报。

上格使用明亮、低饱和的做旧纸张；下格保留用户原图，只叠加轻微的低画质、柔焦、胶片颗粒与记忆感。上下两格共用同一份文字与星星母版，因此所有文字星链和装饰星都能精准对应，仅交换填充材质。

## 主要特性

- 输出一张 3:4 PNG，推荐尺寸为 1536 × 2048 px。
- 上下两格等高，分界线固定在画布高度的 50%。
- 上格为浅色、低饱和旧纸，不使用暗角、烧边或沉重阴影。
- 下格保留原图主体与构图，只添加轻微复古柔化和颗粒。
- 文字与散落星星由同一份母版生成，上下格坐标、大小、旋转和透明度一致。
- 上格星形填充下格照片材质；下格星形填充上格纸张材质。
- 用户指定文字时原样使用；未指定时，根据画面自动选择一个简短单词。
- 五角星是唯一的重复装饰元素。

## 安装

### 方式一：克隆到 Codex Skills 目录

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/YOUR-USERNAME/vintage-star-diptych.git \
  ~/.codex/skills/vintage-star-diptych
```

如果你使用了自定义 `CODEX_HOME`，请把上面的 `~/.codex` 替换成你的实际 Codex 配置目录。

安装后重新打开 Codex 会话，使 Skill 被重新发现。请确保 `SKILL.md` 位于 `vintage-star-diptych` 文件夹根目录。

### 方式二：下载 ZIP

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**。
2. 解压文件。
3. 将解压后的仓库文件夹复制到个人 Skills 目录。
4. 确认目录根部包含 `SKILL.md`，然后重新打开 Codex 会话。

## 使用方法

上传一张照片后直接调用：

```text
Use $vintage-star-diptych to create the image.
```

中文也可以：

```text
用最新版 vintage-star-diptych 生图。
```

指定文字：

```text
用 vintage-star-diptych 生图，文字为 Jennie。
```

如果不指定文字，Skill 会根据画面的氛围、地点、动作或故事，自动选择一个简短且适合星字排版的单词。

## 输入要求

- 一张用户提供的照片。
- 可选：明确指定的单词、短语、符号或图案。
- 建议主体清楚、构图完整；横图与竖图均可，最终会适配到下方宫格。

## 输出规范

- 文件格式：PNG。
- 默认比例：3:4 竖版。
- 默认结构：上下两格，各占画布高度的 50%。
- 上格：浅色、低饱和纸张质感。
- 下格：可辨识的原图与轻复古记忆滤镜。
- 文字位置：每个宫格的视觉中心。
- 上下文字与装饰星：使用同一母版，逐点对齐。
- 最终只交付一张完成图，不公开遮罩、裁切和中间素材。

## 设计原则

1. **原图优先**：不替换人物、不改变身份，不重绘关键面部与动作。
2. **纸图隔离**：纸纹只属于上格；在下格中只能出现在星形遮罩内部。
3. **精准对应**：上下格只交换星形内部材质，不改变星星几何与位置。
4. **明亮纸色**：上格四周保持均匀明亮，不添加暗角或烧边。
5. **轻度复古**：下格只做柔焦、颗粒、轻微褪色与低饱和处理。
6. **可读文字**：星字在缩略图中仍应可识别，并避免过度遮挡主体。

## 自定义

主要规则位于 [`SKILL.md`](./SKILL.md)。可以在其中调整：

- 自动选词逻辑；
- 纸张颜色与纹理强度；
- 星字尺寸、密度和散星节奏；
- 下格复古滤镜强度；
- 主体遮挡时的统一缩放规则。

修改时应保留“同一母版、上下精准对位、仅交换材质”这一核心机制。

## 素材与版权提示

`assets/` 中的图片仅用于说明布局与纸张质感。将仓库设为 Public 前，请确认你拥有这些图片的公开发布和再分发权；如果不确定，请替换为自有素材或先使用 Private 仓库。

本仓库默认不包含许可证。公开开源前，请根据你的发布方式选择合适的代码许可证，并单独确认参考图片的授权范围。
